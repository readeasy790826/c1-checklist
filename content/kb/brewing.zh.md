# 茉莉花茶 Jasmine Green Tea

*Premium · Tapio*

| 材料 | 用量 |
| --- | --- |
| 茶叶 | 50 g |
| 热水（80°C） | 1500 ml |
| 冰块 | 500 g |

1. 将 50 g 茶叶倒入粹茶容器。
2. 倒入 1500 ml **80°C** 热水，盖上盖子，计时 **7 分钟**。
3. 另取茶水容器，提前放入 500 g 冰块。
4. 计时结束前，将茶水过滤出来，倒入装有冰块的容器中。
5. 盖好盖子，保鲜膜密封。粹茶完成。

# 红茶 Assam Black Tea

*Premium · Tapio*

| 材料 | 用量 |
| --- | --- |
| 茶叶 | 70 g |
| 热水（100°C） | 1500 ml |
| 冰块 | 500 g |

1. 将 70 g 茶叶倒入粹茶容器。
2. 倒入 1500 ml **100°C** 热水，盖上盖子，计时 **12 分钟**。
3. 另取茶水容器，提前放入 500 g 冰块。
4. 计时结束，将茶水**过滤两次**，倒入装有冰块的容器混合。
5. 盖好盖子，保鲜膜密封。粹茶完成。

# 抹茶 Matcha

*ALIGN Grade B Barista · ICHA Mocha*

| 材料 | 用量 |
| --- | --- |
| 抹茶粉 | 50 g |
| 温水（50°C） | 200 ml |
| 冷藏冰水 | 1300 ml |

1. 将 50 g 抹茶粉**过筛**至抹茶容器。
2. 倒入 200 ml **50°C** 温水，充分搅拌至粉末完全融合。
3. 加入 1300 ml 冷藏冰水，搅拌混合均匀。
4. 盖好盖子，保鲜膜密封。粹茶完成。

> [!NOTE] 用冷藏冰水（非冰块）确保总量精准，浓度稳定在 1:30。

# 果糖糖浆 Fructose Syrup

*Sugar syrup · Water*

| 材料 | 用量 |
| --- | --- |
| 果糖糖浆 | 500 ml |
| 水 | 100 ml |

![丰年果糖 Fong Leng Fructose](assets/fructose_syrup.jpg)

1. 在标有刻度的 Jar 中倒入 **500 ml** 果糖糖浆，再加入 **100 ml** 水，充分搅拌均匀。
2. 将融合好的糖浆倒入糖浆专用瓶，盖好备用。
