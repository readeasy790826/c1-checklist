W1: Weekly Restart

Purpose: Prevent Windows and application from freezing or hanging over time.

Frequency: Weekly

Time: 5–10 minutes

Videos: N/A

Materials Needed

  • Keyboard
  • Access to admin.hestiarobotics.com

Procedure

Step 1: Set Robot to Maintenance Mode

  1. Log into admin.hestiarobotics.com.
  2. Click Robots and select the correct robot.
  3. Change the status to "In Maintenance".

Step 2: Restart Windows

  1. Press Esc to exit the advertising screen (if needed).
  2. Click Start → Restart to restart Windows.
  3. Wait for Windows to fully boot up before continuing.

Step 3: Restart CoffeeRobot Console

  1. Once Windows has restarted, open the CoffeeRobot Console application.
  2. Wait for it to fully load and connect.

Step 4: Set Robot Back to Online Mode

  1. Log into admin.hestiarobotics.com.
  2. Click Robots and select the correct robot.
  3. Change the status to "Online".
⚠️ Always set the robot to Maintenance Mode FIRST before restarting.
⚠️ Do NOT set Online Mode until Windows and CoffeeRobot Console are fully loaded.
⚠️ Make sure the correct robot is selected before changing status.
