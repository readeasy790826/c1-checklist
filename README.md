# C1 Pro 维护清单

咖啡机日常维护清单，员工通过手机浏览器打开，勾选完成任务后自动提交到 Google Sheets。

## 🔗 访问链接

- **HQ 总览**: https://readeasy790826.github.io/c1-checklist/
- **Davies 店清单**: https://readeasy790826.github.io/c1-checklist/davies/
- **ITC 店清单**: https://readeasy790826.github.io/c1-checklist/itc/

## 📱 如何使用

1. 手机浏览器打开对应店铺链接
2. 点击右上角 **Select All** 一键全选（或逐个勾选任务）
3. 填写日期、时间、异常问题（如有）
4. 点击 **Submit Checklist** 提交

提交后数据自动保存到 [Google Sheets](https://docs.google.com/spreadsheets/d/1MB_agRj8oEzNw6hHnskVjPZO5IKmYUSNKdanr3JAbWo/edit)。

## 🔧 技术架构

- **前端**: HTML + JavaScript + Fetch API
- **后端**: Google Apps Script (Web App)
- **数据库**: Google Sheets
- **托管**: GitHub Pages (免费)
