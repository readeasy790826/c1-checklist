# C1 Pro 维护清单

咖啡机日常维护清单，员工通过手机浏览器打开，勾选完成任务后自动提交到 Google Sheets。

## 访问链接

- **HQ 总览**: https://readeasy790826.github.io/c1-checklist/
- **Davies**: https://readeasy790826.github.io/c1-checklist/davies/
- **ITC**: https://readeasy790826.github.io/c1-checklist/itc/
- **Infinity8**: https://readeasy790826.github.io/c1-checklist/infinity8/

## 如何使用

1. 手机浏览器打开对应店铺链接
2. 打开 Daily / Weekly / Monthly 清单，勾选任务（可用 Select all）
3. 确认日期、时间，异常情况可写在 Notes
4. 点击 **Submit checklist** 提交

提交后数据保存到 [Google Sheets](https://docs.google.com/spreadsheets/d/1MB_agRj8oEzNw6hHnskVjPZO5IKmYUSNKdanr3JAbWo/edit)。

首页 **Abnormal Handling** 为停电、机械臂等应急流程。

## 技术架构

- **前端**: HTML + CSS + JavaScript（GitHub Pages）
- **后端**: Google Apps Script → Google Sheets

开发说明见 `CLAUDE.md`。
