# D0: Enter Maintenance Mode

**Frequency**: Daily  
**Time**: 1-2 minutes  
**Videos**: N/A

---

## Materials Needed

- Keyboard

---

## Procedure

### Step 1: Enter Maintenance Mode

1. Turn on keyboard power.
2. Press **Esc** key to exit advertising screen.
3. Click **Microsoft Edge** browser to enter web interface.
4. Log into **https://admin.hestiarobotics.com/**.
5. Click **Robots** and change the status to **“in maintenance”**.

---

## Important Warnings

⚠️ **Make sure the correct robot is selected before changing status.**  
⚠️ **Do NOT start cleaning before the robot status is changed to “in maintenance”.**  
⚠️ **Keep the robot in maintenance mode until D1-D5 are completed.**
